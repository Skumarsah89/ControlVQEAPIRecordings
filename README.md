# ControlVQEAPIRecordings

Purpose: VQE (Voice Quality Enhancer) Recording captures all audio streams in Teams calls to help investigate poor audio quality or missing audio issues
Key Streams: Records audio before/after processing for near end, and after processing for far end
Platforms: Instructions provided for New Teams on Windows (V2) and Mac (V2)
Important: Capture recordings from the endpoint causing the issue (not the one hearing it); inform customer not to say anything confidential during recording
